# Tarea Git – Control de versiones

Actividad de la asignatura **Bases de Datos Estructuradas y No Estructurados** (Maestría en Estadística, ESPOCH), desarrollada dentro del repositorio del proyecto integrador **FireForest**.

## Objetivo

Aplicar el flujo básico de Git y GitHub: commits descriptivos, uso de `.gitignore`, trabajo en una rama `feature/` e integración de cambios.

## Contenido

| Archivo | Descripción |
|---|---|
| `README.md` | Descripción de la actividad |
| `.gitignore` | Archivos y carpetas excluidos del control de versiones |
| `analisis_datos.py` | Script Python funcional de ejemplo |

## Ejecución

python analisis_datos.py
